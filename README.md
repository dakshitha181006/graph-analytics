# Directed Graph – Degree Analysis

## Description

This Python program creates a **directed graph** using an adjacency list. It calculates and displays the **in-degree** and **out-degree** of each vertex and identifies the vertices with the highest degrees.

## Features

* Create a directed graph
* Store vertices and edges using an adjacency list
* Display the adjacency list
* Calculate in-degree and out-degree
* Find vertices with the highest in-degree and out-degree

## Concepts Used

* Directed Graph
* Adjacency List
* In-Degree and Out-Degree
* Python Classes
* `defaultdict`

```bash
python filename.py
```
